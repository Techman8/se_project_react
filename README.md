# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) uses [Babel](https://babeljs.io/) for Fast Refresh
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) uses [SWC](https://swc.rs/) for Fast Refresh

WTWR (What to Wear) is a responsive React application that helps users choose appropriate clothing based on current weather conditions. The app fetches real-time weather data and displays a curated selection of clothing items suitable for the current temperature and weather conditions.

Key Features:
Real-time Weather Data: Integrates with a weather API to fetch current temperature and conditions
Smart Clothing Recommendations: Displays clothing items filtered by current weather conditions
Interactive Item Gallery: Browse through clothing items with detailed views in modal windows
Temperature-based Filtering: Automatically shows appropriate clothing based on current temperature ranges
Responsive Design: Optimized for both desktop and mobile devices
Modern UI Components: Clean, intuitive interface with modal interactions for detailed item views
How It Works:
Weather Detection: The app automatically fetches weather data for your location on startup
Smart Filtering: Clothing items are filtered and displayed based on current temperature (hot, warm, or cold)
Item Interaction: Click on any clothing item to view it in a detailed modal with larger images
Daily Updates: Current date and weather information are displayed in the header
Problem It Solves:
Ever stood in front of your closet wondering what to wear based on the weather? WTWR eliminates that daily dilemma by providing weather-appropriate clothing suggestions at a glance, helping users dress confidently for any weather condition.
